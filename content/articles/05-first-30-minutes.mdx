<Section id="setup" title="Setup (5 minutes)" />

Before you touch a fader, make sure you can hear both decks in your headphones. Set the master output to a comfortable listening level, then set the cue volume so you can hear the deck you're about to play without blasting yourself.

<Note title="Gain staging">Set each channel's trim so the level meter peaks in the yellow, not the red. Red means clipping — it sounds bad and can damage speakers.</Note>

<Section id="first-transition" title="Your first transition (15 minutes)" />

Load the same track on both decks. Press play on deck 1, then use the pitch fader on deck 2 to match the tempo. When both tracks are at the same BPM, use the jog wheel to align the beats, then slowly bring up deck 2's channel fader while bringing down deck 1's.

Congratulations — you just did a DJ transition. It probably sounded rough. That's normal. Do it 20 more times.

<Section id="next-steps" title="Next steps (10 minutes)" />

- Practice the same transition with two different tracks (not the same track)
- Try using the crossfader instead of the channel faders
- Experiment with the EQ — cut the bass on the incoming track
- Set a hot cue at the start of each track's drop
